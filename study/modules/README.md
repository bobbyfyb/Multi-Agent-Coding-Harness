# 模块设计文档

本目录按系统边界拆解 Multi-Agent Coding Harness。每篇统一回答五个问题：

1. 模块负责什么，不负责什么；
2. 核心数据结构和实际调用链是什么；
3. 为什么采用当前设计；
4. 真实评测遇到过什么问题；
5. 面试中如何解释取舍和演进方向。
